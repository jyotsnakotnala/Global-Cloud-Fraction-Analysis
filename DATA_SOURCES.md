# Data Sources

The datasets used in this project are publicly available.

## ISCCP HGM

NOAA National Centers for Environmental Information

https://www.ncei.noaa.gov/products/international-satellite-cloud-climatology-project

---

## CERES SYN1deg Edition 4.2

NASA Langley Research Center

https://ceres.larc.nasa.gov/data/

---

## CMIP6 Climate Models

Earth System Grid Federation (ESGF)

https://esgf-node.llnl.gov/search/cmip6/

Models used:

- UKESM1-0-LL
- IPSL-CM6A-LR
- MRI-ESM2-0

Variable:
- clt (Cloud Area Fraction)

Scenario:
- Historical
- SSP245

---

Large NetCDF (.nc) files are not included because they exceed GitHub's file size limits.
